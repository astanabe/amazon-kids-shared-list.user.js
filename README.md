# Amazon Kids 共有中コンテンツ抽出

Amazon Kids のペアレントダッシュボード(「アプリとコンテンツの管理」のコンテンツ追加画面)で、次のことをするためのユーザースクリプトです。

- 共有中(トグルがON)の項目だけを一覧にする
- 項目の共有をまとめてON/OFFする

Kindle 本が数千冊あるなど、画面をスクロールして共有中の項目を探すのが現実的でない場合を想定しています。

- ファイル: `amazon-kids-shared-list.user.js`
- バージョン: 0.11.1
- 想定ページ: `https://parents.amazon.co.jp/settings/add-content?isChildSelected=true`
- 動作確認: 構文チェックと、実際の画面を模したテスト用のページでの確認のみ。実際のダッシュボードでは確かめていません(「[注意事項](#注意事項)」参照)

## インストール

### 方法A: ユーザースクリプト用の拡張機能に登録する(推奨)

1. Firefox に [Violentmonkey](https://violentmonkey.github.io/) または [Tampermonkey](https://www.tampermonkey.net/) を入れます。
2. 拡張機能のダッシュボードで新しいスクリプトを作り、`amazon-kids-shared-list.user.js` の中身を全部貼り付けて保存します。
3. ペアレントダッシュボードを開くと、画面右下にパネルが表示されます。

スクリプトは次のURLのページで自動的に起動します。

- `parents.amazon.co.jp` / `.com` / `.co.uk` / `.de` / `.ca`
- 上記のほか `parents.amazon.〇〇` 形式のURL全般

### 方法B: 開発者ツールのコンソールに貼り付ける

1. ダッシュボードのページで F12 キー(または Ctrl+Shift+K)を押して開発者ツールを開き、「コンソール」タブを選びます。
2. いちばん下の入力欄にスクリプトを貼り付けて Enter を押します。
3. 初めて貼り付けたときは警告が出ます。同じ入力欄に `allow pasting` と手で入力して Enter を押してから、もう一度貼り付けてください。

この方法では、ページを再読み込みするとスクリプトは消えます。

### 更新・削除

- **Violentmonkey**:アイコン → 歯車(ダッシュボード)→ 該当スクリプトの「編集」で中身を差し替えます。削除はゴミ箱アイコンです。
- **Tampermonkey**:アイコン → ダッシュボード → 「インストール済みスクリプト」で、スイッチで無効化、ゴミ箱で削除、名前のクリックで編集できます。
- 差し替えたら、ページを必ず再読み込みしてください。古いスクリプトが動いたまま新しいものを貼り付けると、二重起動防止の仕組みにより古い方のパネルがそのまま表示されます。

## 画面構成

画面右下に「共有中コンテンツ抽出」パネルが表示されます。

- **見出し部分**:ドラッグでパネルを移動できます。`_` で最小化、`×` で非表示になります。
- **ステータス欄**:件数や進み具合、診断結果を表示します。
- **一覧**:共有中と判定した項目を表示します(書名と補足情報)。

| ボタン・設定 | 内容 |
|---|---|
| 全件読み込み開始 / 停止 | リストを最後まで自動でスクロールし、共有中の項目を集めます |
| 今の画面をスキャン | 現在読み込まれている範囲だけを調べます |
| 全件共有ON | 先頭から最後までスクロールしながら、すべての項目を共有ONにします |
| 全件共有OFF | 同じく、すべての項目を共有OFFにします(「残すタイトル」に一致するものは除外) |
| 一覧をコピー(TSV) | 共有中の一覧を、タブ区切りでクリップボードにコピーします |
| 記録をクリア | 集めた一覧と、行構造の判定結果を消します |
| 診断 | トグルの検出状況と行構造の判定結果を表示します |
| 1件テスト | 画面内の共有中の1件だけを実際にOFFにし、結果を詳しく表示します |
| OFF(非共有)の行をページ上で隠す | ページ上に共有中の行だけを残します |
| ON/OFF判定を反転 | ON/OFFの意味が逆のページだった場合に使います |
| 画面外の行の描画を省略(軽量化) | 大量に読み込んだときの動作を軽くします(既定でON) |
| 読み込み待ち(秒) | 下端で項目が増えないとき、何秒待ったら終了とみなすか(既定20秒) |
| 一括共有解除(折りたたみ) | 「残すタイトル」の入力、「対象を確認」、「共有解除を実行」 |
| 続きから再開 / 破棄 | 前回の全件共有ON/OFFを続きから再開します(前回の操作があるときだけ表示) |

## 機能一覧

### 1. 共有中の項目の一覧化

- 「全件読み込み開始」を押すと、無限スクロールのリストを最後まで自動でスクロールします。その途中で、トグルがONの項目を記録します。
- 手でスクロールしている間も記録します。トグルを手で切り替えると、一覧にもすぐ反映されます。
- 件数に上限はありません。数千件のリストでも使えます。
- 画面外の行がページから消える作り(仮想スクロール)でも、通過したときに記録するので取りこぼしません。
- 終了の判定:リストの下端で、項目数もページの長さも増えない状態が「読み込み待ち」の秒数続いたら終了します。
  - スピナーなど読み込み中の表示が見えている間は、最大120秒まで待ちます。
  - 下端で待っている間は4秒ごとに1画面分戻って下端へ戻り、続きの読み込みを促します。
- 「もっと見る」などのボタンやリンクを押す処理はありません。ページに対して行うのは、スクロール、状態の読み取り、表示の切り替え、それと一括操作でのトグルのクリックだけです。

### 2. 一覧のコピー

「一覧をコピー(TSV)」で、`タイトル / 補足 / 画像URL` の3列を、タブ区切りでクリップボードにコピーします。表計算ソフトにそのまま貼り付けられます。自動でコピーできなかった場合は、パネル内に表示される欄から手動でコピーしてください。

### 3. OFFの行を隠す

「OFF(非共有)の行をページ上で隠す」をONにすると、ページ上には共有中の行だけが残ります。解除したいもののトグルを手で切る作業がしやすくなります。

### 4. 全件共有ON / 全件共有OFF

- リストの先頭に戻ってから最後までスクロールし、その途中で、目的の状態になっていない項目を順にクリックします。事前の全件読み込みは不要です。
- **誤操作を防ぐ仕組み**:1回押すとボタンが「もう一度押すと実行」に変わり、何をするかがステータス欄に表示されます。5秒以内にもう一度押したときだけ実行されます。
- **途中で止める**:実行中は、押したボタンが「停止」に変わります。
- **全件共有OFFの除外**:「一括共有解除」欄の「共有のまま残すタイトル」に一致する項目は、ON/OFFどちらであっても変更しません。

### 5. 一括共有解除(対象を確認してから実行)

1. 「共有のまま残すタイトル」に、残したい書名を1行に1つずつ入力します。書名の一部でも当てはまります。
2. 「対象を確認」を押すと、解除する件数と残す件数、それぞれの例が表示されます。
3. 「共有解除を実行(N件)」で、その対象だけをOFFにします。

対象になるのは、その時点で読み込まれている共有中の項目です。先に「全件読み込み開始」で最後まで読み込んでおいてください。残すタイトルを書き換えたり読み込み直したりすると、確認からやり直しになります。

### 6. 一括操作での確認と安全装置

一括操作(全件共有ON/OFF、一括共有解除)は、次のように動きます。

- **待たずに次へ進む**:クリックしたら反映を待たず、0.3秒後に次の項目をクリックします。反映の確認は裏で並行して行います。
- **反映待ちは最大8件まで**:反映を確認できていないクリックが8件たまったら、減るまで次をクリックしません。
- **成功の判定**:ページ側が書き込む状態の値(`aria-checked`)を基準にします。チェックボックスの表示上の値だけが変わった場合は、成功と数えません。
- **要素が作り直された場合**:クリックの後にトグルが新しい要素に作り直されても、書名ラベル(`aria-label`)が同じ要素を探して状態を確認します。
- **最後にまとめて再確認**:15秒以内に反映を確認できなかった項目は「未確認」とし、最後に見直します。
  - 遅れて反映されていれば、成功として数えます。
  - まだ変わっていなければ、1回だけ押し直します。
  - 押し直す前に必ず今の状態を読み直すので、二重に切り替わることはありません。
- **自動中断**:次のどれかが起きたら、その場で止めます。
  - 5件続けて切り替わらなかった
  - ページが送る保存の通信が3回失敗した
  - クリックの後にページのURLが変わった
- **誤って押さないもの**:ナビゲーション(ページ上部の「ホーム」ボタンなど)、ヘッダー、メニュー、リンクの中にある要素は対象外です。トグルをクリックする直前にも、本の行のトグルかどうかをもう一度確かめます。
- **進み具合の表示**:ステータス欄に「成功 / 反映待ち / 未確認 / 保存通信(失敗)」の件数を表示します。完了時には再確認の結果(遅れて反映 / 押し直して成功 / 未解決)も表示します。未解決の項目はコンソールに書名を出力します。

### 7. 中断と再開

- 全件共有ON/OFFを実行すると、操作の種類と「残すタイトル」がブラウザに保存されます。
- 次回以降、パネルに「続きから再開」ボタンが表示されます。止まった理由(停止ボタン、自動中断、ページの再読み込み、完了)にかかわらず表示されます。
  - **再読み込みしていない場合**:今のスクロール位置から続けます。
  - **再読み込みした場合**:リストは先頭から読み込み直しになります。切り替え済みの項目は押さずに素早く通過します。
- 「完了」と判定された場合も表示します。下端での読み込みが遅れて、途中で完了と判定されることがあるためです。
- 「破棄」を押すと表示が消えます。
- 「共有のまま残すタイトル」の入力内容は、再読み込みしても残ります。

### 8. 診断と1件テスト

- **診断**:次の内容を表示します。
  - トグル候補の数と種類、ナビゲーションなどで除外した数
  - 判定した行構造(トグルの種類、行までの階層数、行の親要素)
  - スクロール対象の要素
  - 先頭5件のON/OFFとタイトル
- **1件テスト**:画面内の共有中の1件だけをクリックし、5秒後に次の内容を表示します。
  - 押す前と後の状態
  - 実際に押した要素
  - 保存の通信が出たか、その結果

  一括操作の前に、トグル操作が本当に保存されるかを確かめるのに使います。

## 使用方法

### 共有中の項目を確認する

1. コンテンツ追加画面(`/settings/add-content`)を開きます。
2. パネルの「全件読み込み開始」を押します。数千件ある場合は数分かかります。
3. 一覧に共有中の項目が表示されます。必要なら「一覧をコピー(TSV)」で保存します。

### 一括操作の前に確認する(初回は必ず行ってください)

1. 共有中の項目が見える位置までスクロールし、「1件テスト」を押します。
2. ステータス欄の内容を確認します(下の表を参照)。
3. ページを再読み込みし、その本が本当にOFFのままか確かめます。

| 1件テストの結果 | 再読み込み後 | 判断 |
|---|---|---|
| OFFになり、保存通信あり | OFF | 正常です。一括操作を使えます |
| OFFになるが、保存通信が0件 | ONに戻る | 別途保存の操作が必要か、変更が別の仕組みで送られている可能性があります |
| 状態が変わらない | ON | ページがスクリプトのクリックを受け付けていません |

### 特定の本だけを共有し、それ以外をすべてブロックする

1. 現在の状態を「一覧をコピー(TSV)」で保存しておきます(戻す必要が出たとき用)。
2. 「一括共有解除」を開き、共有のまま残したい書名を1行に1つずつ入力します。
3. 「全件共有OFF」を押し、5秒以内にもう一度押します。
4. 最初は数件切り替わったところで「停止」し、ページを再読み込みして結果を確かめてから続けることをおすすめします(「続きから再開」で再開できます)。
5. 完了したら、ページを再読み込みしてもう一度「全件読み込み開始」を実行し、共有中の件数を確かめます。

残したい本がまだ共有されていない場合は、手でONにします。

### すべての項目を共有する

「全件共有ON」を押し、5秒以内にもう一度押します。

## 設定値(スクリプト冒頭の定数)

必要に応じて、スクリプト冒頭の値を書き換えてください。

| 定数 | 既定値 | 内容 |
|---|---|---|
| `STEP_WAIT_MS` | 700 | 下端付近でのスクロールごとの待ち時間(ミリ秒) |
| `FAST_STEP_MS` | 150 | 読み込み済みの範囲を進むときの待ち時間(ミリ秒) |
| `IDLE_SEC_DEFAULT` | 20 | 「読み込み待ち」の初期値(秒)。パネルでも変更できます |
| `LOADING_MAX_SEC` | 120 | 読み込み中の表示がある間に待つ最大時間(秒) |
| `CLICK_INTERVAL_MS` | 300 | 一括操作でのクリックの間隔(ミリ秒) |
| `MAX_INFLIGHT` | 8 | 反映待ちのクリックの上限件数 |
| `PENDING_TIMEOUT_MS` | 15000 | クリック後、反映を待つ時間(ミリ秒)。超えると「未確認」になります |
| `RETRY_VERIFY_MS` | 15000 | 最後の押し直しで反映を待つ時間(ミリ秒) |
| `BULK_MAX_CONSEC_FAIL` | 5 | この件数続けて切り替わらなければ中断します |

Amazon側の応答が遅い場合や、反映待ちが増え続ける場合は、`CLICK_INTERVAL_MS` を大きくするか、`MAX_INFLIGHT` を小さくしてください。

## 仕組み

特定のAPIや、国ごとに変わりやすいクラス名には依存していません。

1. **トグルを探す**:ページ内の `input[type=checkbox]`、`[role=switch]`、`[aria-checked]`、`[aria-pressed]` をトグル候補とします。次のものは除外します。
   - パネル自身
   - 入れ子の内側の要素
   - ナビゲーション、ヘッダー、メニュー、リンクの中にある要素
2. **行構造を判定する**:候補のうち「同じ種類のトグル、同じ階層の深さ、同じ親要素」を持つグループのうち、いちばん大きいものを本の行とみなします(3件以上必要)。以後は、この構造に合うトグルだけを処理します。
3. **新しい分だけ処理する**:新しく現れたトグルだけ、行とタイトルを判定します。タイトルは行の最初のテキスト、なければ画像の代替テキストか `aria-label` です。処理済みの項目は、ON/OFFを読み直すだけです。
4. **クリックの仕方**:人がマウスで押すときと同じ順(pointerdown → mousedown → pointerup → mouseup → click)でイベントを送ります。押す位置は、トグルの中心に実際に表示されている要素です。ただし同じ行の中にある場合だけです。
5. **通信の記録**:ページが送るデータ変更の通信(fetch / XMLHttpRequest のGET以外)を記録し、保存の成否の判断材料にします。
6. **保存するデータ**:ブラウザの `localStorage` に `akids-lastop`(中断した操作)と `akids-keep`(残すタイトル)を保存します。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| パネルが出ない | URLが対象外の可能性があります。コンソールに貼り付ける方法で試すか、アドレスバーのURLを確認してください |
| 0件のまま / 「行構造: 未判定」 | 「診断」を押して表示を確認します。トグルが0個なら、ページのトグルがこのスクリプトの想定と違う作りです |
| ON/OFFが逆に出る | 「ON/OFF判定を反転」をONにします |
| 途中で止まる / 完了と判定される | 「読み込み待ち」を40〜60秒に増やし、「続きから再開」で続けます |
| 動作が重い | 「画面外の行の描画を省略(軽量化)」をONにします(既定でON) |
| 軽量化でスクロール位置が飛ぶ・読み込みが止まる | 軽量化をOFFにします |
| 「未確認」が多い | `CLICK_INTERVAL_MS` を大きくするか、`MAX_INFLIGHT` を小さくします |
| 成功と出たのに、再読み込みするとONに戻っている | 「1件テスト」の結果を確認します(使用方法の表を参照) |
| 「保存通信」が常に0件 | スクリプトがページと切り離された環境で動いている可能性があります(対応ブラウザの項を参照)。コンソールに貼り付ければページと同じ環境で動きます |
| タイトルがずれる | 行の構造が途中で変わっている可能性があります。「記録をクリア」してから再度読み込みます |

## 注意事項

- **実際のダッシュボードでは確かめていません。** 確認したのは、テスト用に作ったページでの動作だけです。一括操作の前に、必ず「1件テスト」と再読み込みで、トグル操作がAmazon側に保存されることを確かめてください。
- **一括操作は少ない件数から試してください。** 一括操作はAmazon側に設定変更を連続して送ります。本番の前に、数件だけ処理して「停止」し、結果を確かめることをおすすめします。
- **元に戻すときは手作業になります。** 誤って切り替えた項目を戻す機能はありません。実行前に「一覧をコピー(TSV)」で現在の状態を保存しておいてください。
- **ページの作りが変わると動かなくなる可能性があります。** Amazon側のページ構成が変わった場合です。まず「診断」の結果で状況を確かめてください。
- **非公式のスクリプトです。** Amazonの公式機能ではありません。利用は自己責任でお願いします。

## 対応ブラウザ

標準的なWebの機能だけを使っているので、Firefox以外(Chrome、Edge、Safari)でも、ユーザースクリプト用の拡張機能に入れるか、コンソールに貼り付ければ動く見込みです。ただし、Firefoxを含めどのブラウザの実物でも確かめてはいません。

- 拡張機能やブラウザの組み合わせによっては、スクリプトがページと切り離された環境で動くことがあります。その場合、保存の通信を記録できません。「保存通信」が0件のままになり、通信の失敗による自動中断も働きませんが、ほかの機能には影響しません。
- 最近のChromeでは、拡張機能の設定で「ユーザースクリプトを許可」をオンにする(または開発者モードを有効にする)必要がある場合があります。
- 軽量化オプション(`content-visibility`)を使えない古いブラウザでは、軽量化されないだけで、ほかの機能には影響しません。
- パネルのドラッグ移動はマウス操作にしか対応していないので、スマートフォンやタブレットではパネルを動かせません。
